\# Reflection



This project helped me understand how to build a small but complete web app from idea to deployment. I learned how to structure a Next.js project, write reusable audit logic, test the logic using Vitest, and deploy the final app on Vercel.



The most useful part was learning that documentation, testing, and deployment are also important parts of real software development. If I had more time, I would improve the UI, add stronger Supabase validation, and make the audit engine more advanced.
